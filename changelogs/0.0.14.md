# Autohand Desktop 0.0.14

## What's new

- Refreshed the macOS installer with Wellington artwork and Axo, the Autohand axolotl. A playful trail points from the app toward Applications, with the draggable icons aligned to the artwork.
- Open owned cloud sessions through Desktop deep links, with account-aware session resolution and dedicated cloud-session windows.
- Updated Desktop documentation and workspace screenshots.

## Downloads

Installers are available for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64. Downloads and release notes are published in the public Autohand Desktop repository; application source remains private. No npm package is published.

Version 0.0.14 uses an explicitly authorized unsigned release exception. macOS builds have an ad hoc integrity seal but are not Apple Developer signed or notarized. Windows installers are not publisher-signed. Artifact provenance records identify the source commit and signing state.
